WORKFLOW

How to use the master admin

A simple publishing workflow for keeping the portfolio current without editing HTML by hand.

01

Classify the project

Keep Mechanical & Machine Design as the core expertise. Assign Aerospace or Marine only as the application area when the project genuinely belongs there. Use Old Projects or Hobbies where appropriate.

02

Add evidence

Attach genuine CAD renders, FEA/CFD plots, drawings, screenshots or downloadable engineering files. Never fabricate numerical results.

03

Publish

Save the individual project to GitHub. The project index should keep the newest projects first so new engineering work is immediately visible.

04

Prepare for interviews

Generate specialization-specific presentations so Aerospace and Marine interview portfolios remain separate while both retain Mechanical & Machine Design as the underlying core.

Content integrity

This admin is intentionally data-driven. Do not use it to claim employment, certifications, client work, simulation results, awards or professional qualifications that are not supported by your actual records.
